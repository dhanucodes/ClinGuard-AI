# ClinGuard AI

**A patient-adaptive, explainable and agent-assisted framework for simulated patient monitoring and context-aware anomaly detection.**

> Research prototype notice: ClinGuard AI is an educational/research software prototype. Its initial evaluation uses synthetic data. It is not a medical device, does not diagnose patients, and has not been clinically validated.

## Project goals

ClinGuard AI investigates whether patient-specific adaptive baselines, hybrid anomaly detection, data-quality-aware verification, and evidence-grounded explanations can make simulated physiological anomaly alerts more reliable and traceable.

The project is designed to run without restricted medical datasets, institutional permissions, physical sensors, or IoT hardware. Its primary dataset will be generated by the project's own synthetic-data generator.

## Software requirements

- Windows 10/11, macOS, or Linux
- Python 3.11 recommended for this project scaffold
- Visual Studio Code (or another Python-capable editor)
- Git
- A GitHub account
- Internet access for installing dependencies

No GPU is required for the initial modules. We will decide whether any later model needs accelerated hardware before introducing it.

## Windows setup

Open PowerShell or the VS Code terminal.

### 1. Check installations

```powershell
python --version
git --version
```

If `python` is not recognised, try:

```powershell
py --version
```

### 2. Create and activate a virtual environment

Run these commands from the project root:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, use Command Prompt instead:

```cmd
.venv\Scripts\activate.bat
```

### 3. Upgrade pip and install the initial dependencies

```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Only foundational dependencies are included initially. Additional packages will be added when their modules are implemented.

### 4. Verify Python

```powershell
python --version
python -m pip list
```

## Git and GitHub setup

Create an empty GitHub repository named `ClinGuard-AI`. For the first push, do not initialise the remote repository with a README, license, or .gitignore because those files are already present locally.

From the project root:

```powershell
git init
git add .
git commit -m "chore: create ClinGuard AI project scaffold"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with the HTTPS or SSH URL shown by GitHub. Never put passwords or access tokens in source files or chat.

## Environment variables

Copy `.env.example` to `.env` when a module needs local configuration. Keep `.env` private and never commit it. The example file contains placeholders only.

## Development principles

- Implement and test one module at a time.
- Keep the analysis engine independent from the user interface.
- Use reproducible synthetic data and fixed random seeds.
- Split evaluation data by patient where appropriate to reduce leakage.
- Preserve experiment configurations and actual results.
- Do not fabricate performance metrics, citations, or clinical claims.
- Keep explanations grounded in outputs produced by the software.
- Require human review; this prototype must not be used for clinical decisions.
